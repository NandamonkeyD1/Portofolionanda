Case Study 01 // Education Technology

E-Raport Management System

An integrated academic governance and digital grading platform engineered for transparent evaluation between schools, educators, students, and parents.

01 / Project Overview

E-Raport Management System is a specialized web application engineered to modernize student grading workflows across vocational high schools (SMK). It connects subject teachers, homeroom advisors, curriculum coordinators, and students within a unified portal for recording daily tasks, midterm exams, and automated final report card generation.

02 / Problem & Motivation

Prior to system implementation, grade recording was executed manually through disconnected spreadsheets by individual teachers. This caused frequent weighted formula calculation errors, severe delays during semester card printing, and prevented parents from accessing timely visibility into academic progress.

03 / My Role & Contributions

As the Full-Stack Developer on this project, my core responsibilities included:

  • Architecting the normalized relational MySQL database schema for students, classrooms, courses, and grading criteria.
  • Developing backend business logic in PHP Laravel for score validation and automated weighted average calculations.
  • Implementing Role-Based Access Control (RBAC) across 4 user tiers: School Administrators, Subject Teachers, Homeroom Advisors, and Students.
  • Designing an efficient batch score-entry interface and building automated PDF report card exports in compliance with institutional standards.

04 / Technical Stack

PHP Laravel Framework MySQL Relational DB Blade Templating Bootstrap CSS JavaScript (ES6) DomPDF Exporter

05 / Design & Architecture Decisions

We implemented an MVC pattern complemented by a Service Layer to isolate calculation algorithms from controllers. Database indexing on foreign keys (student_id, course_id) was tuned to ensure multi-semester analytical queries execute in sub-100ms.

06 / Screenshots & Implementation Evidence

The interface provides role-scoped sidebars, batch score inputs with client-side bounds checking (0–100), and on-screen report card rendering before export.

07 / Challenges & Lessons Learned

The primary challenge stemmed from varying weight allocations across curricula (Kurikulum 2013 vs. Kurikulum Merdeka). We resolved this by building a dynamic rule configuration table, enabling administrators to modify course grading weights on the fly without changing source code.

08 / Outcome & Project Status

The system was successfully deployed for live academic evaluation. Grade compilation time—which previously took weeks of manual reconciliation—was compressed to just a few hours after teacher submissions completed.
